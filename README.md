### Sentiment Classification

Dans ce repository, l'objectif est de développer un classifieur de textes permettant de prédire le sentiments exprimés dans un texte. La classification de texte est un domaine clé du traitement automatique du langage naturel, qui repose sur des algorithmes d'apprentissage automatique pour analyser et comprendre le contenu sémantique. Nous nous concentrons sur l'utilisation de réseaux de neurones récurrents (RNN) et leurs variantes avancées, telles que les LSTM (Long Short-Term Memory) et GRU (Gated Recurrent Unit), pour la classification d'émotions ainsi que l'utilisation d'un LLM pré-entrainé (DISTILBERT).
